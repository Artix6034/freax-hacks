# Brev CPU deployment

Node.js 24+, 2 vCPU / 8 GiB RAM достаточно для UI, файлового хранилища и внешнего модельного API. GPU не нужен. На момент проверки каталог GCP n2d-standard-2 показывал $0.066919/ч за вычисления, диск оплачивается отдельно. Это котировка каталога, не гарантия цены. Три попытки создания через CLI/API вернули HTTP 400, успешных экземпляров нет. Облачный URL пока отсутствует.

## На выделенной Linux-машине

1. Установить Node.js 24 из официального источника, создать системного пользователя `freax`, каталог `/opt/freax` для кода, `/var/lib/freax` для записей. Один процесс на каталог: два экземпляра с одним файловым store запускать нельзя.
2. Перенести только `src/`, `config/`, `scripts/`, `integrations/`, `package.json` и документацию. Не публиковать data, .env, .env.brev, tmp, output или исследовательские входы. Для демонстрации исходного DEV разрешено отдельное приватное размещение `data/dev/api-response.json` на собственной машине, а не в публичном репозитории.
3. Серверную AI-конфигурацию сохранить в `/etc/freax.env`, владелец root:freax, права 0640. Настройки по `.env.example`. `CQA_PUBLIC_ORIGIN` равен точному внешнему HTTPS origin. Для CRM добавить точный `CQA_EMBED_ORIGINS`. Ни ключ, ни signed endpoint не передаются браузеру.
4. Проверить путь `/usr/local/bin/node` в `deploy/freax.service`, установить unit в `/etc/systemd/system/`, включить `systemctl enable --now freax`. Оценки сохраняются в `/var/lib/freax`. Резервное копирование этого каталога выполняется при остановленной очереди.
5. Проверить `curl http://127.0.0.1:3000/healthz`. `model_configured=true` означает наличие настроек, а не доказательство доступности модели. Платный smoke-запрос запускается отдельно кнопкой на согласованном диалоге.
6. Для Brev: `brev ports open INSTANCE 3000 --protocol http --json` создаёт по умолчанию приватный HTTP endpoint для владельца. Допуск проверяющего: `--authorize EMAIL`. Не использовать `--public` для незащищённого платного API. Сохранить реальный URL и выставить CQA_PUBLIC_ORIGIN перед запуском сервиса. Иной HTTPS reverse proxy обязан ограничивать доступ к AI API.

HTML UI не требует отдельной учётной записи приложения. Приватный Brev gateway требует вход в NVIDIA. Для публичного демо нужен согласованный шлюз доступа; без него открытие платного endpoint создаёт возможность чужих расходов и чтения истории.

## Проверка перед передачей

`node --test "tests/*.test.js"`

`node --env-file-if-exists=.env scripts/prepare-prod.mjs --preflight`

`node --env-file-if-exists=.env scripts/start-prod.mjs`

Проверить импорт, выбранный чек-лист, одну оценку, точные источники, апелляцию и решение, новую версию критериев, историю и JSON. Полный DEV повторять не требуется. PROD results создаётся только после выдачи реальных 10 чатов.
