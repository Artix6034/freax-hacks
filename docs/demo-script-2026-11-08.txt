Основной показ — приложение, 3–5 минут:
1. Открыть сохранённый DEV без новых вызовов, выбрать существующую оценку.
2. Показать балл, N/A и точную цитату: нажатием перейти к реплике и соседнему контексту.
3. Открыть правила: последняя версия, редактирование критериев, сохранение новой версии. Старые оценки сохраняют свой снимок.
4. Показать историю, апелляцию и отдельный пересмотр; для сохранения демонстрационных изменений использовать тестовый диалог.
5. Показать готовую пакетную очередь и экспорт JSON. Не запускать повторно все DEV и не оценивать SWAP без инструкции.
