2. После выдачи реальных десяти контрольных чатов
Сохранить файл организаторов, например data/prod-control.json. Сначала офлайн-проверка:
  node --env-file-if-exists=.env scripts/prepare-prod.mjs --dataset data/prod-control.json
Затем один оплачиваемый запуск:
  node --env-file-if-exists=.env scripts/prepare-prod.mjs --dataset data/prod-control.json --run
Если выдан group_id вместо файла:
  node --env-file-if-exists=.env scripts/prepare-prod.mjs --group-id ВЫДАННЫЙ_ID --run
Не придумывать PROD group_id. Подписанный endpoint уже хранится только на сервере.
После прерывания:
  node --env-file-if-exists=.env scripts/prepare-prod.mjs --resume
Явный новый платный повтор только технических сбоев:
  node --env-file-if-exists=.env scripts/prepare-prod.mjs --resume --retry-failed
Готовые и частичные попытки не переоцениваются молча. CLI сохраняет исходный набор, run_id, входы/версии/usage, затем пишет results/prod/results.json. Если исходная оценка partial/failed, официальный результат этого чата имеет status error, criteria [], score null с причиной. Это ограничение формата, не фальшивый ноль.
Подробности: docs/prod-ready-2026-11-08.txt.
