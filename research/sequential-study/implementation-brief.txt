Freedom Broker CQA — предложение внедрения после исследования, 2026-11-07

Первым реализовать L_seq: фрагмент -> извлечение фактов -> проверка цитат -> журнал/состояние -> отдельный финальный вызов по ПОЛНОМУ оригиналу -> существующий валидатор -> расчёт кодом. Сохранить текущий A1 как C0 control. Отдельная финальная стадия не требует другой модели и не гарантирует независимость ошибок.

Гибрид не выбран победителем. Classifier + LLM имеет смысл как CPU event detector/отбор промежуточных проверок, если докажет event recall, качество финальных критериев и пользу по всем расходам. Обязательный full judge не удалять на основании classifier negative. Новый criterion без поддерживаемого класса -> LLM fallback, не автоматическое переобучение и не "нарушений нет".

AI labels могут быть silver train, никогда gold test. Null/unreviewed не negative.
