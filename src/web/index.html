Пакетная оценка

Оценивается весь загруженный набор по выбранному чек-листу. Настройки сохраняются на весь прогон. Каждый диалог — отдельный запрос к модели.

Продолжение сохраняет готовые результаты и не повторяет сбои автоматически. Частичные оценки сохраняются; в официальной выгрузке неизвестность обозначается ошибкой, а не N/A.
