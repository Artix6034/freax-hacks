Пакет выполняется, пока страница открыта. Готовые результаты сохраняются; после возврата обработка продолжится.

Параметры прогона

Оцениваются все загруженные диалоги по выбранному чек-листу.

Готовые оценки сохраняются. Повтор сбоев запускает новые запросы. Неопределённые ответы в выгрузке обозначаются ошибкой.
