Перед началом

Частые вопросы.

Полная инструкция
Что можно загрузить?

Один JSON-диалог, массив диалогов или ответ API организаторов. В сервисе также есть загрузка по группе API. Для знакомства доступен вымышленный учебный диалог.

Что оценивается в звонках?

Текст транскрипта с учётом устной коммуникации. Ссылку на запись можно открыть отдельно. Темп, дикция и произношение в этой версии автоматически не анализируются.

Почему итог бывает не рассчитан?

Неопределённый критерий с положительным весом блокирует общий итог. Остальные ответы и их исходные баллы сохраняются. Неопределённость не заменяется нулём или N/A.

Можно ли изменить восемь стартовых критериев?

Да. Можно менять инструкции, веса, шкалы и состав чек-листа. Официальный формат сдачи требует исходные восемь критериев и допустимые типы ответов; совместимость проверяется отдельно.

Что происходит после апелляции?

Проверяющий подтверждает либо меняет ответ с обоснованием. Код пересчитывает финальный итог. Исходный AI-результат и его доказательства остаются в истории.

Нужно ли держать вкладку открытой?

В размещённой версии очередь набора продолжает работу, пока страница открыта. Готовые оценки сохраняются. Самостоятельный Node.js сервер выполняет пакет в запущенном процессе.
