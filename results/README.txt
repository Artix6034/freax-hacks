Файлы сдачи создаёт JavaScript-экспортёр: results/dev/results.json и results/prod/results.json.
Команда: Freax. Формат: приложение к гайду, JSON 1.0.

Готовые файлы появятся после обработки полного исходного набора и успешной проверки.
Пустые шаблоны, синтетические оценки и придуманные контрольные ID сюда не записываются.
Исходные Evaluation остаются в data/; частичные результаты не уничтожаются.
В файле сдачи неопределённость передаётся как status:error, а null означает только N/A.

Команды запуска и проверки описаны в основном README.md.
Скрипт не вызывает модели, не создаёт Git-репозиторий и ничего не публикует.
